2. Conceptual Summary: Multiplicative Updates

When computing errors backward, adjustments to any given parameter are driven by multi-variable interactions:

Weight Adjustment (Δwij) = Learning Rate (η) × Node Blame (δj) × Input Signal (xi)

This creates explicit operational rules of thumb:

  • If two variables are stationary, parameters change in direct proportionality to the remaining item.
  • If a connection was dead or inactive (xi = 0), no update occurs.
  • If a hidden node uses a standard ReLU activation function (max(0, z)) and outputs 0, its blame score drops cleanly to zero, insulating its upstream path from updates during that cycle.
  • Bias weights (bj) are updated using the same rule, but with a constant input of 1 instead of xi.
