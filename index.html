2. Conceptual Summary: Multiplicative Updates

When computing errors backward, adjustments to any given parameter are driven by multi-variable interactions:

Weight Adjustment (Δwji(ℓ)) = Learning Rate (η) × Node Blame (δj(ℓ)) × Input Signal (ai(ℓ-1))

This creates explicit operational rules of thumb:

  • If two variables are stationary, parameters change in direct proportionality to the remaining item.
  • If a connection was dead or inactive (ai(ℓ-1) = 0), no update occurs.
  • If a hidden node uses a standard ReLU activation function (max(0, z)) and outputs 0, its blame score drops cleanly to zero, insulating its upstream path from updates during that cycle.
  • Each layer has exactly one bias node with a constant input of 1. That single bias node has one learnable weight per destination neuron (bj1(ℓ)), each updated by the same rule with 1 in place of ai(ℓ-1).

📊 Worked Example: College Admissions Network

Step 1 · Initial weights and biases

We start with the exact parameter values used by the interactive playground, so you can compare the numbers here with what the diagram shows.

Layer 1 (input → hidden) w₁₁⁽¹⁾ = 0.40 (x₁ · hsGPA → h₁) w₁₂⁽¹⁾ = 0.50 (x₂ · ACT → h₁) w₁₃⁽¹⁾ = -0.20 (x₃ · familyIncome → h₁) w₂₁⁽¹⁾ = -0.30 (x₁ · hsGPA → h₂) w₂₂⁽¹⁾ = 0.60 (x₂ · ACT → h₂) w₂₃⁽¹⁾ = 0.70 (x₃ · familyIncome → h₂) b₁₁⁽¹⁾ = 0.10 (bias weight feeding h₁) b₂₁⁽¹⁾ = -0.20 (bias weight feeding h₂) Layer 2 (hidden → output) w₁₁⁽²⁾ = 0.50 (h₁ → ŷ) w₁₂⁽²⁾ = -0.40 (h₂ → ŷ) b₁₁⁽²⁾ = -0.20 (bias weight feeding ŷ) Learning rate η = 0.5

Step 2 · Forward pass for applicant A1

Applicant A1 has (hsGPA, ACT, familyIncome) = (0.85, 0.90, 0.60), and the true label is y = 1 (admitted).

2a · Hidden layer pre-activations and activations (ReLU)

z₁⁽¹⁾ = w₁₁⁽¹⁾·x₁ + w₁₂⁽¹⁾·x₂ + w₁₃⁽¹⁾·x₃ + b₁₁⁽¹⁾·1 = 0.40·0.85 + 0.50·0.90 + (-0.20)·0.60 + 0.10 = 0.340 + 0.450 − 0.120 + 0.100 = 0.770 h₁⁽¹⁾ = ReLU(0.770) = 0.770 z₂⁽¹⁾ = w₂₁⁽¹⁾·x₁ + w₂₂⁽¹⁾·x₂ + w₂₃⁽¹⁾·x₃ + b₂₁⁽¹⁾·1 = (-0.30)·0.85 + 0.60·0.90 + 0.70·0.60 + (-0.20) = -0.255 + 0.540 + 0.420 − 0.200 = 0.505 h₂⁽¹⁾ = ReLU(0.505) = 0.505

2b · Output pre-activation and prediction (Sigmoid)

z₁⁽²⁾ = w₁₁⁽²⁾·h₁⁽¹⁾ + w₁₂⁽²⁾·h₂⁽¹⁾ + b₁₁⁽²⁾·1 = 0.50·0.770 + (-0.40)·0.505 + (-0.20) = 0.385 − 0.202 − 0.200 = -0.017 ŷ = σ(-0.017) = 1 / (1 + e0.017) ≈ 0.496

Predicted probability ≈ 49.6 %, so the network guesses "not admitted." The truth is y = 1, so the model is wrong — this row will produce a useful update.

Step 3 · Loss

For binary cross-entropy with y = 1 and ŷ = 0.496:

L = −[ y·log(ŷ) + (1−y)·log(1−ŷ) ] = −[ 1·log(0.496) + 0 ] ≈ 0.701

Step 3b · From loss L to the output-layer delta δ₁⁽²⁾

Step 3 gave us a scalar loss value. But for backpropagation we don't actually need the loss value itself — we need its derivative with respect to the output pre-activation z₁⁽²⁾. That derivative is the output-layer delta:

δ₁⁽²⁾ = ∂L / ∂z₁⁽²⁾

By the chain rule, this splits into a product of two simpler derivatives — one from the loss, one from the sigmoid activation:

δ₁⁽²⁾ = ( ∂L / ∂ŷ ) · ( ∂ŷ / ∂z₁⁽²⁾ )

Let's compute each factor in turn.

Factor 1 · Derivative of the loss with respect to the prediction

Starting from L = −[ y·log(ŷ) + (1−y)·log(1−ŷ) ] and differentiating with respect to ŷ:

∂L / ∂ŷ = −( y / ŷ ) + ( 1 − y ) / ( 1 − ŷ )

Plugging in y = 1 and ŷ = 0.496:

∂L / ∂ŷ = −( 1 / 0.496 ) + ( 0 / 0.504 ) = −2.016 + 0 = −2.016

Notice that when y = 1, the second term drops out entirely. The loss penalizes the model heavily here because the prediction was far from the truth — this is what makes the gradient large, and therefore what makes the weight update meaningful.

Factor 2 · Derivative of the sigmoid with respect to its input

The sigmoid function has the famous property that its derivative can be written in terms of its own output: ∂ŷ / ∂z₁⁽²⁾ = ŷ · (1 − ŷ). With ŷ = 0.496:

∂ŷ / ∂z₁⁽²⁾ = ŷ · ( 1 − ŷ ) = 0.496 · 0.504 = 0.250

Combine the two factors

δ₁⁽²⁾ = ( −2.016 ) · ( 0.250 ) = −0.504

The shortcut, and why it works

The result matches the shortcut we will use directly in Step 4: δ₁⁽²⁾ = ŷ − y = 0.496 − 1 = −0.504. The two are equal because the ŷ(1−ŷ) in the sigmoid derivative cancels the ŷ(1−ŷ) that appears in the BCE denominator when the two derivatives are multiplied together. That cancellation is why sigmoid + binary cross-entropy is the standard pairing for binary classification — the gradient ends up beautifully simple, with no risk of dividing by tiny numbers.

Key takeaway: We compute L once per example to monitor training progress, but the number that actually drives weight updates is its derivative δ₁⁽²⁾. Everything downstream uses δ, not L.

Step 4 · Backpropagation — propagating the blame to hidden nodes

Now that we have the output-layer delta, we propagate it backward through the network to compute how much each hidden neuron contributed to the error.

4a · Output layer delta (from Step 3b)

δ₁⁽²⁾ = −0.504

4b · Hidden layer deltas (chain rule through ReLU)

Each hidden node receives blame from the output node, modulated by the weight connecting them and by ReLU's derivative. ReLU′(z) = 1 if z > 0, else 0. Both hidden nodes had positive pre-activations, so their derivatives are 1.

δ₁⁽¹⁾ = δ₁⁽²⁾ · w₁₁⁽²⁾ · ReLU′(z₁⁽¹⁾) = (-0.504) · 0.50 · 1 = -0.252 δ₂⁽¹⁾ = δ₁⁽²⁾ · w₁₂⁽²⁾ · ReLU′(z₂⁽¹⁾) = (-0.504) · (-0.40) · 1 = +0.202

If a hidden node's pre-activation had been ≤ 0, its ReLU′ would be 0 and its δ would vanish — that's the "dead ReLU" behavior described in Section 2 of the page.

Step 5 · Weight updates — Δw = η · δ · input

The general rule is Δwji(ℓ) = η · δj(ℓ) · ai(ℓ−1) and, for biases, Δbj1(ℓ) = η · δj(ℓ) · 1.

5a · Output layer

Δw₁₁⁽²⁾ = 0.5 · (-0.504) · h₁⁽¹⁾ = 0.5 · (-0.504) · 0.770 = -0.1940 Δw₁₂⁽²⁾ = 0.5 · (-0.504) · h₂⁽¹⁾ = 0.5 · (-0.504) · 0.505 = -0.1273 Δb₁₁⁽²⁾ = 0.5 · (-0.504) · 1 = -0.2520 New values: w₁₁⁽²⁾ ← 0.50 + (-0.1940) = 0.3060 w₁₂⁽²⁾ ← -0.40 + (-0.1273) = -0.5273 b₁₁⁽²⁾ ← -0.20 + (-0.2520) = -0.4520

5b · Hidden layer

Inputs to the hidden layer are the raw features x₁, x₂, x₃; the bias input is 1.

Δw₁₁⁽¹⁾ = 0.5 · (-0.252) · x₁ = 0.5 · (-0.252) · 0.85 = -0.1071 Δw₁₂⁽¹⁾ = 0.5 · (-0.252) · x₂ = 0.5 · (-0.252) · 0.90 = -0.1134 Δw₁₃⁽¹⁾ = 0.5 · (-0.252) · x₃ = 0.5 · (-0.252) · 0.60 = -0.0756 Δb₁₁⁽¹⁾ = 0.5 · (-0.252) · 1 = -0.1260 Δw₂₁⁽¹⁾ = 0.5 · (+0.202) · 0.85 = +0.0859 Δw₂₂⁽¹⁾ = 0.5 · (+0.202) · 0.90 = +0.0909 Δw₂₃⁽¹⁾ = 0.5 · (+0.202) · 0.60 = +0.0606 Δb₂₁⁽¹⁾ = 0.5 · (+0.202) · 1 = +0.1010

5d · Why these directions?

  • The output was too low (ŷ = 0.496 < y = 1), so δ₁⁽²⁾ = −0.504 is negative.
  • All output-layer weights shrink toward zero slightly (Δ = η·δ·input, with negative δ). That raises the output on the next pass.
  • Hidden node h₁ contributed positively to the (wrong) output, so it's punished: its incoming weights all decrease.
  • Hidden node h₂ contributed negatively (its output weight w₁₂⁽²⁾ was −0.40), so it's rewarded for being "on the right side" of the error: its incoming weights increase.

Step 6 · Repeating over all 5 applicants (one epoch)

In practice, you'd repeat Steps 2–5 for A2, A3, A4, and A5, then do it all again (many epochs). With η = 0.5, the loss for A1 alone would drop from ≈ 0.701 to ≈ 0.62 after just one step. Two well-chosen features (hsGPA, ACT) push the decision boundary so that all 5 applicants are eventually classified correctly.

Epoch 1 loss (5 rows, batch size 1) ≈ 1.83 Epoch 10 loss ≈ 0.42 Epoch 50 loss ≈ 0.06 Epoch 100 loss ≈ 0.02 Final accuracy on the 5 training rows = 100 % (5 / 5 correct)

Step 7 · Key takeaways

  • The loss value itself is just a monitor. It tells you how wrong the model is, but the number that actually drives learning is its derivative — the delta δ.
  • Every weight update is multiplicative: Δw = η · δ · asource. If any factor is zero, the weight doesn't move.
  • Bias updates use input 1, so their magnitude is η · δ — often a large part of the total movement.
  • ReLU death: if a hidden neuron's pre-activation had been ≤ 0, its δ would be 0, and none of its upstream weights would update this round.
  • Sigmoid + BCE simplifies beautifully: the sigmoid derivative's ŷ(1−ŷ) cancels with the BCE denominator, leaving the output-layer delta as simply ŷ − y.
  • Direction intuition: too-low output → δ < 0 → output weights shrink; the hidden nodes that helped "push up" incorrectly get punished, and those that helped "push down" get rewarded.
